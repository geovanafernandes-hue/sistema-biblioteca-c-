# Roteiro de apresentação individual

## Duração sugerida
5 a 7 minutos.

## 1. Abertura
"Bom dia. Vou apresentar meu projeto de Programação Estruturada em C++. O tema escolhido foi um sistema de gerenciamento de biblioteca. O objetivo é cadastrar livros, consultar registros, exportar dados para TXT, fazer exclusão lógica e contabilizar os livros ativos."

## 2. Explicação inicial dos slides
- Mostrar o objetivo do sistema.
- Explicar as funcionalidades principais.
- Explicar a estrutura `Livro`.
- Explicar como o sistema salva os dados em arquivo binário.

## 3. Demonstração prática
### Livros para cadastrar
- Livro 1: O Cortiço — Aluísio Azevedo — 1890
- Livro 2: Dom Casmurro — Machado de Assis — 1899

### Ordem da demonstração
1. Cadastrar os 2 livros.
2. Consultar o código 1.
3. Listar ou contabilizar os livros ativos.
4. Exportar para TXT.
5. Excluir logicamente o livro de código 2.
6. Mostrar a quantidade novamente.
7. Consultar o código 2 e mostrar que ele não está mais ativo.

## 4. Encerramento
"Com esse projeto, consegui aplicar os conceitos de programação estruturada, struct, funções e manipulação de arquivos. O sistema salva os registros, permite consulta e usa exclusão lógica para manter a integridade do arquivo binário."
